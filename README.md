# PlaceMate - Campus Placement Portal

PlaceMate is a BTech project website for managing college placement activities. It includes student, recruiter, and placement officer workflows in a clean static frontend.

## Main Modules

- Student profile and eligibility management
- Recruiter and job drive listing
- Application status tracking
- Placement event calendar
- Demo login panel for role-based access
- Admin-style placement statistics

## How to Run

Open `index.html` directly in a browser, or run a local server:

```bash
python3 -m http.server 4173
```

Then visit:

```text
http://127.0.0.1:4173
```

## Files

- `index.html` - page structure and content
- `styles.css` - responsive visual design
- `script.js` - job filtering and demo login interaction
- `assets/placement-hero.png` - generated hero image used by the website
